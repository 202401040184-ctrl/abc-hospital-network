# ABC Hospital Network

## Project Overview
A hospital network simulation created using Cisco Packet Tracer.

## Features
- VLAN segmentation for six hospital departments
- Router-on-a-stick inter-VLAN routing
- DHCP for department PCs
- DNS and HTTP hospital web server
- ACL-based department traffic restrictions

## Technologies Used
- Cisco Packet Tracer
- VLANs and 802.1Q trunking
- DHCP, DNS, HTTP
- Cisco IOS ACLs

## Files
- `Hospital_Network.pkt` — Network simulation
- `ABC_Hospital_Network_Project_Report.pdf` — Project report
